Next-Generation Smart Features

By using a Vision-Language Model (VLM), the AI doesn't just read code—it sees the car's digital state just like a human driver.

Smart Vehicle Diagnostics

The VLM visually monitors the digital cluster to track engine oil levels, heat warnings, and upcoming service dates. It proactively alerts the driver before a breakdown occurs.

Fuel & Mileage Insights

Calculates real-time local conditions, analyzing sudden drops in mileage or low fuel levels, and automatically routes the driver to the nearest optimized fuel station.

Emergency SOS Integration

If the VLM detects a critical local failure (e.g., severe overheating), it instantly triggers a protective SOS feature, guiding the driver to safety.

The Hybrid VLM Engine

To make this affordable for all vehicles, we engineered a brilliant Hybrid Architecture that minimizes cloud costs while maximizing capabilities.

Tier 1: Fast API (The Backbone)

For standard actions, the system executes an internal API call immediately. It is instantaneous, zero-cost, and works perfectly offline.

Tier 2: The Vision Fallback

For complex dashboard analysis or 3rd-party apps, our Python engine sends a screen buffer to Gemini 2.5 Pro. The AI visually reads the gauges, warning lights, and UI elements to make smart decisions.

The Future: Offline & Scalable

Our roadmap for taking this prototype to final production hardware.

The ₹4,000 Hardware Upgrade

To eliminate cloud dependency, we propose an optional hardware upgrade. By adding just ₹4,000 (~$50) in RAM/NPU power to the head unit, Tata can run a small, distilled version of this AI 100% offline directly on the car's chip.

Cloud-Connected Fleet Ideation

When connected to the internet, these agents communicate. If thousands of cars report poor mileage on a specific stretch of highway via their VLMs, Tata can aggregate this data for future smart-city routing ideas.
